# Earth Rules

The user manual for being a person: earthrules.org.

A free, plain guide to what everyone is expected to know and do as an adult: a yearly calendar of what comes due, life-stage checklists, taxes, credit, moving, checkups, making friends, what's normal, and rules by state (Ohio first).

- Static site on GitHub Pages, custom domain in `CNAME`.
- Pages are generated by `_build/build.py`. Edit content there, then run `python3 _build/build.py` from the repo root.
- Every page lists its official sources and the date they were checked.
- Built to WCAG 2.1 AA. GoatCounter visit counter, no cookies.

Created and maintained by Travis Vought.
